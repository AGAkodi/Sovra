# Storyline D: "It already happened" (88 s, 1920×1080, 30 fps)

**Recommended.** It's grounded in three real incidents, so the film answers "why does this exist?" before showing the product.

**Device:** life before and after. Real events first, then the same kind of attack replayed live against Sovra on NEAR testnet.

**Form:** object-to-object chain. Each incident's key word, "transfer", "dashboard", "memory", becomes the Sovra screen that answers it.

**Honesty rules for this film:**
- Incident facts are stated as reported, with the source on screen.
- Freysa is described as a public challenge built to be beaten.
- AIXBT is described as a breached dashboard, not a manipulated AI.
- The replays are labelled "Replayed on NEAR testnet with Sovra's live vault". We never claim Sovra would have saved those specific funds. We show how it handles the same kind of attack.

## Sources

- Freysa, Nov 2024: about $47,000 prize pool, won by persuading the agent to approve a transfer; 195 players, 482 attempts.
  - The Block: https://www.theblock.co/post/328747/human-player-outwits-freysa-ai-agent-in-47000-crypto-challenge
  - Cointelegraph: https://cointelegraph.com/news/crypto-user-convinced-ai-bot-transfer-47k
- AIXBT, 18 Mar 2025: an attacker breached the bot's dashboard and sent 55.5 ETH (about $106,200) through two prompts. The maintainer said the AI wasn't manipulated.
  - Cointelegraph: https://cointelegraph.com/news/hacker-breaches-ai-crypto-bot-aixbt-steals-55-eth
  - AI Incident Database: https://incidentdatabase.ai/cite/1003
- "AI Agents in Cryptoland", Princeton and the Sentient Foundation, 2025: a planted false memory made an ElizaOS agent send funds to an attacker; prompt-based defenses failed.
  - Paper: https://arxiv.org/abs/2503.16248
  - Decrypt: https://decrypt.co/318200/elizaos-vulnerability-ai-gaslit-losing-millions
